# Review: file_upload_filename_bases_common

- **Source:** Conventional upload form purposes and existing project profile examples.
- **Why it exists:** Avoid embedding one hard-coded filename stem in every non-quick profile.
- **Must contain:** Neutral, short stems that describe common uploaded-object roles.
- **Must not contain:** Extensions, paths, usernames, secrets, or attack-specific terms.
- **Doubtful entries:** Names are illustrative and do not claim statistical coverage.
- **Missing entries added:** `avatar` and `document` for common application workflows.
- **Entries removed:** Technology and shell-specific names.
- **Final result:** Five deterministic filename stems.
