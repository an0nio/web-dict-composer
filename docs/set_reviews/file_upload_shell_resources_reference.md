# Review: file_upload_shell_resources_reference

- **Source:** Official Kali package pages and the named upstream repositories.
- **Why it exists:** Make webshell collections and reverse-shell sources discoverable without
  indexing or importing their executable contents.
- **Must contain:** Package names, documented Kali paths, upstream links, and a clear distinction
  between webshells and reverse shells.
- **Must not contain:** Shell source code, copied payloads, automatic downloads, or instructions
  that target a live system.
- **Doubtful entries:** The relationship between the two Kali trees may vary by package version, so
  the text follows Kali's documented layout without assuming they are independent copies.
- **Missing entries added:** Reverse-shell terminology and aliases for catalog search.
- **Entries removed:** Webshell tags from PentestMonkey because it is cataloged specifically as a
  reverse shell.
- **Final result:** One local human reference and three separately searchable external references,
  grouped by `shell-resources` while retaining their specific categories.
