# LFI and Path Traversal sets

The active LFI sets separate syntax from destinations:

- `traversal/` — one parent-directory step per line;
- `targets/` — relative Linux, Windows, PHP source, and log paths;
- `wrappers/` — deliberately read-only PHP filter prefixes;
- `suffixes/` — experimental version- and parser-dependent suffixes.

Traversal depth is generated by bounded profile rules. Do not store repeated depths, complete LFI
payloads, traversal-plus-target combinations, credentials, write/execution wrappers, or enormous
framework dumps as atoms.

OWASP, PHP, operating-system, and web-server documentation provide primary context. SecLists LFI
collections are external direct-use wordlists and review sources, not built-in compositional sets.
